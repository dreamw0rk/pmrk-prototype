# PMRK-ID.BO.19.AGG.v1 Профиль контрагента — вкладка «Общие сведения»

> Прототип ПМРК работает на моках без бэкенда (`src/shared/mock/*`, см. `README.md`).
> Этот документ фиксирует целевой контракт API для вкладки «Общие сведения» карточки
> контрагента (`GeneralTab`, `src/pages/CounterpartyProfile.tsx:428-649`) в формате,
> принятом для БО/эндпойнтов CRADLE-ID, — как основу для бэкенд-реализации.
> Связанные требования: ФТ-19.1, ФТ-19.2 (`design/03_requirements.md:452-456`).

## GET /counterparties/{uid}/profile/general

Возвращает агрегат `CounterpartyProfileGeneral` — все данные вкладки «Общие сведения»
одним запросом.

| gpnAffiliationFlag | Признак принадлежности к ГК ГПН | string | + | Например: «ВЗЛ ГПН» / «Не аффилирован» |
| hasCollateral | Наличие обеспечения (признак) | boolean | + | Без цветовой индикации на карточке (в отличие от остальных булевых полей блока) |
| hasNegativeSecurityInfo | Наличие негативной информации от службы безопасности | boolean | + | На карточке — с цветовой точкой: `true` — красная, `false` — зелёная |

| paymentDiscipline | Платёжная дисциплина за последние 12 месяцев | string ENUM | + | Возможные значения: `Без нарушений`, `Единичные случаи возникновения ПДЗ`, `Неоднократное возникновение ПДЗ`. Тон: первое значение — зелёный, второе — жёлтый, третье — красный |

## Сценарий формирования ответа

| № | Шаг | Альтернативный сценарий |
|---|---|---|
| 1 | Процесс получает запрос, содержащий `uid` контрагента | |
| 2 | Процесс получает из внутреннего хранилища данные БО Организация с указанным `uid` (PMRK-ID.BO.19.1) | 2а. Контрагент не найден — возвращается 404 |
| 3 | Процесс получает записи БО Дополнительный вид деятельности, у которых `companyId = uid` | 3а. Данные не найдены — `additionalOkveds` возвращается пустым массивом |
| 4 | Процесс получает записи БО Изменение наименования / ОПФ, у которых `companyId = uid`, отсортированные по `date` | 4а. Данные не найдены — `nameChanges` возвращается пустым массивом, на карточке выводится пояснение об отсутствии изменений |
| 5 | Процесс определяет статус контрагента в ПМРК (`pmrkStatus`): `Действующий`, если по контрагенту открыт действующий кредитный лимит, иначе — `Потенциальный` | |
| 6 | Процесс получает записи БО Связь контрагента с ДО ГК ГПН, у которых `companyId = uid`; группирует по `block` в порядке справочника блоков, внутри группы — сначала основное ДО (`primary = true`), затем по алфавиту | 6а. Данные не найдены — на карточке блок ДО не выводится |
| 7 | Процесс получает признаки обеспечения, негативной информации СБ и контроля ЛФП (`hasCollateral`, `hasNegativeSecurityInfo`, `lfpContractControl`, `lfpAdvanceControl`) по контрагенту | |
| 8 | Процесс получает показатели деловой репутации (`experience`, `paymentDiscipline`) по контрагенту за последние 12 месяцев | |
| 9 | Процесс получает сведения о контрагенте с платформы деловых отзывов «Мнения» (БО PMRK-ID.BO.19.6) по `inn` | 9а. Данные не найдены — раздел «Внутренние рейтинги и оценки» на карточке не выводится |
| 10 | Процесс получает прогноз вероятности дефолта по горизонтам 30+/90+/180+ дней от модели АГАТА (БО PMRK-ID.BO.19.7) | 10а. Данные не найдены — блок «Предиктивная аналитика» на карточке не выводится |
| 11 | Процесс получает признак нахождения контрагента в списке «Под особым контролем» и, если признак установлен, — причину и комментарий согласования | 11а. Признак не установлен — `reason` и `comment` возвращаются как «—» |
| 12 | Процесс проверяет статус юридического лица контрагента; если `status = Банкротство` — формирует ссылку на карточку в Едином Федеральном реестре сведений о банкротстве по `inn` | 12а. Статус не «Банкротство» — `hasFedresursRecord` и `fedresursLink` возвращаются как «нет данных» |
| 13 | Процесс собирает даты актуальности источников (`asOf`) по разделам вкладки | 13а. Дата для раздела «Под особым контролем» не задана — используется дата раздела «Общие сведения» |
| 14 | Возвращает успешный ответ, содержащий агрегат PMRK-ID.BO.19.AGG.v1 | |
